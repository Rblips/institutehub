### Abstract

While the Rust type system guarantees safe memory lifetimes and data-race freedom for safe code, high-performance concurrency primitives rely on `unsafe` blocks. We develop a mechanized verification framework in Coq that formalizes Iris separation logic specifications directly against the LLVM IR generated by rustc, proving linearizability and lack of memory reclamation faults across lock-free queues and skip lists.
