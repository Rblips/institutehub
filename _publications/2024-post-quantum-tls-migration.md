### Abstract

As post-quantum key encapsulation mechanisms (such as ML-KEM / Kyber) are integrated into production web servers, network handshake latency and packet fragmentation overhead must be addressed. We benchmark hybrid classical/quantum cipher suites across standard Nginx reverse proxies, outlining optimal TLS configuration parameters for zero-downtime enterprise adoption.
